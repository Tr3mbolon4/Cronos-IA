# Windows SmartScreen

O instalador `0.1.0` nao possui assinatura comercial. Em maquinas novas, o Windows SmartScreen pode exibir aviso de aplicativo desconhecido.

Politica desta fase:

- nao adicionar assinatura falsa;
- nao habilitar auto-update;
- publicar SHA-256 para verificacao manual;
- tratar assinatura comercial como etapa futura.
