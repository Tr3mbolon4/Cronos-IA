## Procedimento Administrativo Preparado

O script `scripts/prepare-local-whisper.ps1` agora aceita:

- `-ImportModelPath`
- `-ModelSha256`
- `-DryRun`
- `-SelfTest`

Fluxo permitido:

1. Obter `ggml-base.bin` em rede autorizada a partir da origem oficial.
2. Calcular SHA-256 na origem.
3. Transferir por canal administrativo aprovado.
4. Executar o script com `-ImportModelPath`.
5. O script valida nome exato, SHA-256 de 64 caracteres e tamanho real antes da copia.
6. O script recalcula SHA-256 no destino.
7. Somente depois atualiza o manifest.

Exemplo sem registrar caminho pessoal:

```powershell
.\scripts\prepare-local-whisper.ps1 `
  -UseExistingFiles `
  -ImportModelPath "<canal-aprovado>\ggml-base.bin" `
  -RuntimeSha256 "3716AC2A3203DEF41CB49FC0CB49A03A4E4B75D7C5A1889F77164553D75FE060" `
  -ModelSha256 "60ed5bc3dd14eea856493d334349b405782ddcaf0028d4b5df4088345fba2efe"
```

## Validacoes Adicionadas

O runtime Tauri agora recusa:

- `runtimeSha256` ou `modelSha256` vazio, placeholder, SHA-1 de 40 caracteres, tamanho diferente de 64, prefixo `SHA256:`, espaco ou caractere nao hexadecimal;
- `modelName` diferente de `ggml-base.bin`;
- `modelFile` diferente de `models/ggml-base.bin`;
- `modelSize` igual a zero;
- `modelVariant` diferente de `base`;
- `multilingual` diferente de `true`;
- manifest sem `importedFromApprovedChannel`, `sourceAndDestinationHashesMatch` e `integrityValidated` como `true`;
- caminhos absolutos ou pessoais em `runtimeFile`, `modelFile`, `modelSource` ou `officialSource`;
- nomes contendo `.en.`;
- runtime diferente de `bin/whisper-cli.exe`.

O script tambem recusa arquivo vazio, arquivo menor que o esperado para `ggml-base.bin` e ponteiro Git LFS em vez do modelo real.

Depois da importacao aprovada, o manifest deve registrar `modelSha256`, `modelSize`, `modelVariant`, `multilingual`, `officialSource`, `importedFromApprovedChannel`, `sourceAndDestinationHashesMatch` e `integrityValidated`.
