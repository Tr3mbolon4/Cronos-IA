# CRONOS v0.3.0 - Fase 5.2 Runtime Whisper Local

## Objetivo

A Fase 5.2 implementa o caminho real para STT local do CRONOS: captura de microfone, conversao para PCM WAV 16 kHz mono, bridge frontend -> Tauri, validacao de runtime/modelo por manifest e execucao controlada do `whisper-cli.exe`.

Esta fase nao inicia a Fase 6 e nao gera instalador RC final.

## Runtime Escolhido

- Provider: `cronos-local-whisper`
- Runtime: `whisper.cpp`
- Versao fixada no manifest: `v1.8.5`
- Executavel esperado: `whisper-cli.exe`
- Origem: `https://github.com/ggml-org/whisper.cpp/releases/tag/v1.8.5`
- Licenca: MIT
- Arquitetura: Windows x86_64 CPU

O runtime ainda nao foi baixado, compilado ou versionado nesta execucao. O script `scripts/prepare-local-whisper.ps1` prepara o artefato somente com origem HTTPS e SHA-256 esperado informado explicitamente.

## Modelo

- Modelo padrao: `ggml-base.bin`
- Origem: `https://huggingface.co/ggerganov/whisper.cpp`
- Familia: OpenAI Whisper base multilingual em formato GGML
- Licenca: MIT
- Idioma alvo: pt-BR
- Tamanho esperado aproximado: 142 MB

O modelo nao e baixado em runtime e nao e adicionado ao Git. O uso somente e liberado quando o manifest possui SHA-256 real e o arquivo instalado bate com o hash esperado.

## Estrutura de Recursos

Estrutura definida:

```text
frontend/src-tauri/resources/voice/whisper/
  bin/
    whisper-cli.exe
  models/
    ggml-base.bin
  licenses/
    whisper.cpp-LICENSE.txt
    model-source.txt
  manifest.json
```

`bin/*.exe`, `bin/*.dll` e `models/*.bin` estao ignorados pelo Git. O diretorio `resources/voice/whisper` esta configurado em `tauri.conf.json` para ser empacotado quando os artefatos existirem localmente no processo de release.

## Script de Preparacao

Arquivo:

- `scripts/prepare-local-whisper.ps1`

O script:

- usa versao fixada;
- exige HTTPS;
- exige SHA-256 esperado para runtime e modelo;
- falha se o hash divergir;
- copia `whisper-cli.exe`;
- baixa ou usa `ggml-base.bin`;
- atualiza `manifest.json`;
- nao roda no startup do CRONOS;
- nao executa download dentro do aplicativo.

## Captura e WAV

Arquivo:

- `frontend/src/features/voice/providers/localAudioCapture.ts`

Fluxo:

1. `getUserMedia` abre o microfone.
2. Web Audio captura amostras mono.
3. O audio e reamostrado para 16 kHz.
4. O audio e codificado como PCM WAV 16-bit.
5. O frontend envia bytes WAV ao Tauri.

O CRONOS nao renomeia WebM/Opus para WAV. O header WAV e gerado de forma explicita.

## Bridge Tauri

Arquivo:

- `frontend/src-tauri/src/local_whisper.rs`

Comandos:

- `get_local_whisper_status`
- `transcribe_local_audio`
- `cancel_local_transcription`

Seguranca aplicada:

- nenhum caminho arbitrario vindo do frontend;
- manifest validado;
- runtime e modelo restritos ao diretorio permitido;
- SHA-256 obrigatorio;
- WAV validado;
- limite de tamanho;
- temporario em `%LOCALAPPDATA%/CRONOS/runtime/voice-temp`;
- execucao sem shell;
- argumentos fixos;
- timeout;
- uma solicitacao cancelavel por request id;
- stdout/stderr limitados;
- limpeza de temporarios.

## Execucao do Whisper

Parametros iniciais:

- `-m <modelo>`
- `-f <audio.wav>`
- `-l pt`
- `-otxt`
- `-of <saida-controlada>`
- `-nt`

A saida preferencial e arquivo `.txt` temporario controlado. O stdout e usado apenas como fallback.

## Cancelamento

O frontend gera `requestId` seguro. Ao cancelar:

- captura e encerrada;
- TTS e interrompido;
- `cancel_local_transcription` tenta matar o processo local;
- resultado tardio e ignorado pelo `operationRef`;
- temporarios sao removidos pelo fluxo de transcricao.

Ao fechar a janela, o Tauri chama `cancel_all_transcriptions`.

## Limitacoes

Sem runtime/modelo reais, `cronos-local-whisper` continua indisponivel no app. Isso e intencional: o CRONOS nao baixa artefatos em runtime e nao usa WebView como fallback silencioso.
