# CRONOS v0.3.0 - Correcao do pacote local de voz

## Contexto

Build validada pelo proprietario para chat e isolamento:

- `C:\CRONOS-VALIDACAO-v0.3.0-5b01742\cronos-desktop.exe`
- Commit: `5b01742`

Ao acionar o microfone, a interface retornou:

`Manifest local de voz nao encontrado: O sistema nao pode encontrar o caminho especificado. (os error 3)`

## Diagnostico

O pacote entregue contem os arquivos de voz em:

- `C:\CRONOS-VALIDACAO-v0.3.0-5b01742\resources\voice\whisper\manifest.json`
- `C:\CRONOS-VALIDACAO-v0.3.0-5b01742\resources\voice\whisper\bin\whisper-cli.exe`
- `C:\CRONOS-VALIDACAO-v0.3.0-5b01742\resources\voice\whisper\models\ggml-base.bin`
- DLLs em `resources\voice\whisper\bin`

O codigo anterior resolvia apenas:

- `CRONOS_LOCAL_WHISPER_DIR`, quando definido;
- `app.path().resource_dir()\voice\whisper`;
- fallback de desenvolvimento via `CARGO_MANIFEST_DIR`.

Esse fluxo nao registrava os caminhos tentados, retornava erro generico de manifest ausente e podia falhar quando o `resourceDir` real do executavel entregue nao correspondia ao layout copiado manualmente para validacao.

## Correcao aplicada

- Resolver primeiro pela pasta real do executavel entregue: `<exeDir>\resources\voice\whisper`.
- Manter suporte ao `app.path().resource_dir()\voice\whisper`.
- Manter override administrativo explicito via `CRONOS_LOCAL_WHISPER_DIR`.
- Adicionar busca controlada em:
  - `%LOCALAPPDATA%\CRONOS\models\voice\whisper`
  - `%LOCALAPPDATA%\CRONOS\models\voice`
  - `%PROGRAMDATA%\CRONOS\models\voice\whisper`
  - `%PROGRAMDATA%\CRONOS\models\voice`
- Substituir erro generico por codigos:
  - `VOICE_MANIFEST_NOT_FOUND`
  - `VOICE_MANIFEST_INVALID`
  - `VOICE_RUNTIME_NOT_FOUND`
  - `VOICE_MODEL_NOT_FOUND`
  - `VOICE_RUNTIME_START_FAILED`
- Registrar origem selecionada, caminho de origem e caminhos procurados no status do provider.
- Iniciar `whisper-cli.exe` com `CREATE_NO_WINDOW` no Windows.
- Registrar execucoes em `%LOCALAPPDATA%\CRONOS\logs\whisper.log`.
- Endurecer `scripts/build-isolated.ps1` para exigir manifest, runtime, DLLs e modelo na pasta isolada entregue.
