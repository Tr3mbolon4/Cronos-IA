## Selected Default

`cronos-local-whisper` using `whisper.cpp` with `ggml-base.bin`.

Reasons:

- local CPU execution;
- no Python runtime requirement;
- no account/API;
- no automatic download;
- compatible license;
- straightforward packaged resource model;
- future path for CUDA without changing the public provider API.
