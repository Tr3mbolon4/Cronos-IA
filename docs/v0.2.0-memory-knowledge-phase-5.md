# CRONOS v0.2.0 - Fase 5: Interfaces de Memoria e Biblioteca

Data: 2026-07-21
Branch: `feature/v0.2.0-memory-knowledge`

## Objetivo

Adicionar as primeiras telas funcionais de Memoria, Biblioteca e Recuperacao de Conhecimento ao CRONOS Desktop, consumindo somente as APIs ja criadas nas Fases 2, 3 e 4.

Esta fase nao implementa voz, palavra de ativacao, automacao, controle do computador, programacao autonoma, Gmail, calendario, GitHub, cameras, Qdrant, plugins, multi-owner, instalador final ou release v0.2.0.

## Cliente API

O `ApiClient` centraliza:

- URL dinamica do runtime;
- token de runtime;
- token autenticado do proprietario;
- timeout por chamada;
- erros estruturados;
- upload com `FormData`;
- chamadas abortaveis via `AbortSignal`.

Tokens nao sao registrados em logs nem exibidos na interface.

## Navegacao

O menu lateral agora alterna entre:

- Dashboard inicial;
- Memoria;
- Biblioteca.

A navegacao ocorre por estado React, sem reload completo da aplicacao. Os demais itens continuam preservados como entradas do dashboard atual.

## Riscos e Pendencias

- A UI de Memoria usa paginacao simples; filtros avancados combinados ainda precisam de validacao com base grande.
- A busca semantica da v0.2.0 usa o provider local oficial do CRONOS, sem dependencia obrigatoria de Sentence Transformers ou Hugging Face.
- A tela de Biblioteca mostra status de provider, modo lexical/hibrido e fallback lexical, mas ainda nao oferece configuracao visual de providers futuros.
- As telas de Aprendizado, Memoria profunda e Biblioteca avancada ainda podem ser refinadas nas fases seguintes.
