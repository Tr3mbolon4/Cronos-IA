# Política de segurança

## Reporte responsável

Não publique vulnerabilidades, credenciais, tokens, dados pessoais ou detalhes de instalações locais em *issues* públicos.

Para reportar uma possível vulnerabilidade, entre em contato de forma privada com a responsável pelo projeto e inclua apenas as informações necessárias para reproduzir o problema com segurança.

## Diretrizes para contribuições

- Nunca envie arquivos `.env`, dados de usuários, conversas, PDFs privados, backups ou registros de diagnóstico reais.
- Use valores fictícios nos exemplos de configuração e nas capturas de tela.
- Revogue e substitua qualquer credencial exposta antes de registrar uma correção.

## Escopo

Esta política se aplica ao código-fonte, scripts de empacotamento e documentação do projeto Cronos-IA.
